Standard/Accepted Values for Environmental Factors

## TEMPERTURE
--> Minimum Temperature: 12^C
--> Maximum Temperature: 20^C

## HUMIDITY
--> Minimum Humidity: 85%
--> Maximum Humidity: 95%

## HYSTERESIS LOGIC
Temp: 15C - 18C
Humidity: 90% - 93%


## Cooling Mode
Peltier -> ON
Vent -> CLOSE (Servo -> 0)
Fan -> ON (Circulation)

## Increase Temp Mode
Peltier -> OFF
Vent -> OPEN (Servo -> 90)
Fan -> OFF

## Humidity Mode
Humidifier -> ON
Vent -> CLOSE (Servo -> 0)
Fan -> OFF

## Reduce Humidity Mode
Humidifier -> OFF
Vent -> OPEN (Servo -> 90)
Fan -> ON (Circulation)
